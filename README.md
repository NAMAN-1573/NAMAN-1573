## 🚀 Featured project — `frontend-qa`

[![npm version](https://img.shields.io/npm/v/frontend-qa?logo=npm&color=CB3837)](https://www.npmjs.com/package/frontend-qa)
[![license](https://img.shields.io/npm/l/frontend-qa)](https://www.npmjs.com/package/frontend-qa)
[![docs](https://img.shields.io/badge/Live%20docs-frontendprobe.vercel.app-000000?logo=vercel)](https://frontendprobe.vercel.app/)

> **A local-first, deterministic frontend runtime inspection &amp; QA tool for React / Next.js — shipped as an npm package with a built-in MCP server. Zero LLM/API dependencies.**

Point it at a running app and it drives a real Chromium browser (via Playwright) to collect **evidence-based** QA signals — every issue is tagged *Measured / Observed / Static Analysis / Heuristic*, so nothing is presented as fact that wasn't actually measured:

- 🧭 **Runtime scan** — console errors, failed network requests (secrets redacted), screenshots, load timing
- ♿ **Accessibility** — axe-core audits
- ⚡ **Performance** — Lighthouse metrics
- 🖼️ **Visual &amp; bundle** — screenshot diffing and bundle-size analysis
- 🔎 **Static analysis** — ts-morph code intelligence
- 🤖 **MCP server** — exposes all of the above to AI clients (Claude, etc.) over stdio

**Privacy-first:** source is never uploaded; Authorization / Cookie / token / secret values are redacted. Everything runs on your machine.

```bash
# install, then scan a running app
npm i frontend-qa
npx frontend-qa scan --url http://localhost:5173
```

🌐 **Live docs:** https://frontendprobe.vercel.app/ &nbsp;·&nbsp; 📦 **npm:** https://www.npmjs.com/package/frontend-qa &nbsp;·&nbsp; 💻 **Source:** https://github.com/mishra-naman/frontend-Probe

**Stack:** TypeScript · pnpm + Turborepo monorepo · Playwright · axe-core · Lighthouse · ts-morph · Zod · Model Context Protocol SDK · Astro (docs)
